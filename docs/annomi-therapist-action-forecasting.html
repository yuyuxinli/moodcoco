AnnoMI 是第一个针对动机性访谈（Motivational Interviewing）做 utterance 级行为标注的开放数据集。 133 段对话被 10 位专家标注了治疗师的每一句话属于 reflection / question / therapist_input / other， 以及来访者的每一句话属于 change talk / sustain talk / neutral。 配套论文提出 Therapist Action Forecasting 任务：给定对话上下文，预测治疗师下一步应该采取什么行为。 对 moodcoco 的价值在于：它为我们的 Skill 路由提供了一套经过临床验证的行为分类法， 可以直接映射到 listen / untangle / psychoeducation / face-decision 等 Skill。

标签体系层级

Reflection 反映
  • Simple
    重复或轻微改述来访者的话，不增加新含义
  • Complex
    深层改述、推断隐含情绪、赋予新视角
Question 提问
  • Open
    开放式提问，引导来访者自由探索
  • Closed
    封闭式提问，确认事实或二选一
Therapist Input 治疗师输入
  • Information
    提供客观知识或心理教育
  • Advice
    给出建议或行动方向
  • Negotiation
    协商目标或计划
  • Options
    列出可选方案供来访者选择
Client Talk Type 来访者话语
  • Change Talk
    朝向改变的语言：愿望、能力、理由、需要、承诺
  • Sustain Talk
    维持现状的语言：为不改变辩护
  • Neutral
    既不朝向改变也不维持现状
Other
不属于以上三类的治疗师话语，例如寒暄、过渡语、确认收到等。不含子类型。

高质量 vs 低质量 MI 对话差异

High-Quality MI

  • 更多 complex reflection，深入共情
  • 更多 open question，引导自主探索
  • advice 以 negotiation / options 形式出现，尊重自主权
  • 来访者产出更多 change talk
  • 治疗师 : 来访者 说话比例约 1:1 或更低
  • 遵循 MI Spirit：合作、唤起、尊重自主

Low-Quality MI

  • 以 simple reflection 为主，缺乏深度
  • 更多 closed question，限制探索空间
  • 直接给 advice 而非提供 options
  • 来访者维持更多 sustain talk
  • 治疗师说得比来访者多
  • 偏向指导式而非合作式

标注对话示例（构造）

Topic: 减少饮酒 · High-Quality MI
Therapist 听起来你一方面觉得喝酒帮你放松，另一方面又担心对健康的影响。 complex reflection
Client 对，其实上次体检医生说我肝指标偏高，有点害怕。 change talk
Therapist 那个体检结果让你有些担心。如果情况继续下去，你觉得会怎样？ open question
Client 可能会更糟吧，但说实话，下班那杯酒真的是我一天最放松的时刻。 sustain talk
Therapist 有些人在类似情况下会尝试几种不同的方式来放松——运动、正念、或者减少到每周两次。你想了解一下吗？ input: options
Client 运动倒是可以试试，我以前跑步的时候心情确实不错。 change talk
Therapist 你记得跑步带来的那种好感觉。 simple reflection

AnnoMI → moodcoco Skill 映射

AnnoMI 标签   moodcoco Skill 说明
reflection: simple → listen / validation 重复来访者的话，表达「我听到了」
reflection: complex → listen (slow deeper) 深层改述，走 slow path 做更深的共情
question: open → untangle 开放式提问帮来访者理清思路
question: closed → untangle (clarify) 封闭式确认，用于澄清关键事实
therapist_input: info → psychoeducation 心理教育，提供客观知识
therapist_input: advice → face-decision 给出方向建议（需谨慎，尊重自主权）
therapist_input: options → face-decision 列出选项供来访者自行决定
therapist_input: negotiation → face-decision 协商目标和计划
other → - 寒暄、过渡语，无需映射到 Skill

Client Talk Type 对路由的意义

AnnoMI 对来访者话语的三分类，为 Skill 路由提供了信号输入：

change talk 来访者已有改变动机 → 路由可倾向 face-decision，帮助落地行动
sustain talk 来访者在抵抗 → 路由应回到 listen + untangle，不要硬推
neutral 来访者中性 → 继续探索，用 open question 激发

局限性

  • 1 仅覆盖 MI 场景 — 动机性访谈只是心理咨询的一个分支。不涵盖 CBT、ACT、psychodynamic 等其他流派的治疗师行为。
  • 2 无 crisis 标注 — 数据集不包含自杀/自伤/危机干预场景。moodcoco 的 crisis Skill 无法从该数据集获得训练信号。
  • 3 无 calm-body 映射 — MI 对话不涉及身体导向的放松技术（呼吸练习、正念扫描等），因此 calm-body Skill 在此没有对标。
  • 4 face-decision 覆盖有限 — MI 中的 advice/options/negotiation 更偏向行为改变计划，不完全等同于 moodcoco 中更广泛的决策辅助场景。
  • 5 仅英文对话 — 所有对话均为英文，文化适配和中文语境下的表现未经验证。
  • 6 示范性对话 vs 真实咨询 — 数据来自 YouTube 训练视频而非真实临床录音，可能存在「表演」偏差。
