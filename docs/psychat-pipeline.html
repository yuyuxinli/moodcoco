PsyChat 五模块流水线解读

PsyChat: A Client-Centric Dialogue System for Mental Health Support

Qiu, Li, Ma, Lan arXiv 2312.04262 CSCWD 2024 2024-03 v2

30 秒版本

现有心理对话系统只关注咨询师策略，忽略来访者行为。PsyChat 用五模块流水线先识别来访者在做什么（11 种行为），再选策略（12 种），再生成 10 条候选回复并排序选最优。核心观点：不先理解来访者，策略选择就是盲的。

五模块流水线架构

用户每发一条消息，依次经过五个模块。前两步是分析，第三步组装 prompt，第四步批量生成，第五步精选最优。

关键设计决策：M1 和 M2 独立于 LLM 生成环节。即使换掉底层 LLM（M4），行为理解和策略选择能力不受影响。这让系统可以在小模型上保持专业判断。
各模块详解
M1

来访者行为识别 Client Behavior Recognition

识别来访者当前话语属于哪种行为模式。这是 PsyChat 最核心的创新点：先看来访者在做什么，才能决定咨询师该做什么。

输入
对话历史 [SEP] 当前来访者话语
输出
11 个行为类别之一

技术方案

Chinese RoBERTa-large 全连接分类层 85.97% Accuracy

分类器在 18,824 条训练样本上训练，来自 Xinling 真实咨询数据集。行为分类法来自 Li et al. (2023) "Understanding Client Reactions in Online Mental Health Counseling"。

来访者 11 种行为分类

积极反应 5 类

确认 Confirming理解/同意咨询师的表述
提供信息 Giving Info提供咨询师要求的信息
合理请求 Request寻求澄清、理解或建议
延伸 Extending同意并深入分析、反思自身认知/行为
重新建构 Reformulating内省咨询师干预后提出自己的观点或行为模式

消极反应 6 类

困惑 Confusion表示不理解或无法回答
防御 Defending坚持原有观点，美化/辩护自己
自责/绝望 Self-criticism自我批评、绝望、表示无法改变
转移话题 Changing Topics从当前问题转向其他话题
焦点脱离 Disconnection脱离讨论焦点，关注自己的兴趣
讽刺回答 Sarcastic表达不满，质疑或嘲讽咨询师的干预
M2

咨询师策略选择 Counselor Strategy Selection

不使用传统分类器，而用稠密检索找到训练集中最相似的对话上下文，然后直接取该样本的策略标签。好处：不需要为策略训练单独的分类器，策略集合可以随数据集扩展。

输入
对话上下文 + 来访者行为标签
输出
12 个策略类别之一 + 匹配的示例对话

技术方案

BAAI/bge-large-zh-v1.5 欧氏距离检索 80.15% Accuracy

检索库由训练集所有对话构建。推理时找到最相似的历史会话，取其策略标签作为本轮策略。副产品：匹配到的示例对话会传给 M3 做 few-shot demonstration。

咨询师 12 种策略分类

支持性策略 8 种

重述 Restatement反馈来访者话语的内容和含义
情感反映 Reflection明确反映来访者的情绪状态
自我暴露 Self-disclosure分享咨询师的个人经历/感受

M3

输入组装器 Input Packer

将前两个模块的输出 + 检索到的示例对话 + 原始对话历史，打包成一条结构化的 instruction-following prompt。

输入
行为标签 + 策略标签 + 对话历史 + 检索示例
输出
格式化的 Instruction Prompt

Prompt 结构

// 1. 角色定义
你是一名专业心理咨询师，正在为来访者提供支持...
// 2. 示例对话（from M2 retrieval）
Demonstration: 来访者说"..." 策略: [情感反映] 回复: "..."
// 3. 当前对话历史
来访者行为: [防御] | 建议策略: [解释]
对话: 来访者: "..." / 咨询师: "..." / 来访者: "..."
// 4. 生成指令
请根据以上信息生成咨询师的回复。

关键设计：示例对话来自 M2 的检索结果，不是随机选取。这保证了 few-shot demonstration 与当前场景高度相似。

M4

回复生成器 Response Generator

基于组装好的 prompt，一次性生成 10 条候选回复，供 M5 筛选。

输入
M3 组装的 Instruction Prompt
输出
10 条候选咨询回复

ChatGLM2-6B LoRA 微调 8192 token 上下文

M5

回复筛选器 Response Selection

从 10 条候选中选出最优。解耦生成与质控：生成模型只管数量，筛选模型只管质量。

输入
对话历史 + 10 条候选回复
输出
得分最高的 1 条回复

技术方案

Cross-Encoder 对话历史 + 候选回复 → 向量 → 线性层 → 得分

训练方式

  • 正样本：ground truth 回复（1 条）
  • 负样本：其余 9 条候选（1:9 比例）
  • 损失函数：Cross-entropy loss
  • Recall@1/10 = 81.84%

与 moodcoco fast/slow 架构的对应关系

PsyChat 的五模块流水线与 moodcoco 的 Speaker (Fast) + Thinker (Slow) 双 agent 架构有直接的映射关系。

PsyChat 模块 moodcoco 对应 对应方式
M1 来访者行为识别 Slow / Thinker Thinker 读 Skill 后做用户状态分析，cross-turn 写入 slow_guidance，功能等同于行为识别
M2 策略选择 Slow / Thinker Thinker 选择 skill_bundle + dynamic_inject，决定本轮采用哪些策略和技术框架
M3 输入组装器 cross-turn 注入 Thinker 产出通过 FastThinkDeps 的 slow_guidance / skill_bundle / retrieval_block / dynamic_inject 四个字段注入 Speaker
M4 回复生成器 Fast / Speaker Speaker 基于 Thinker 注入的指导生成最终用户可见回复，通过 UI tool 推送
M5 回复筛选器 当前无直接对应 moodcoco 暂无"生成多条 → 选最优"机制。可在 Thinker 增加 critic 环节，或用 best-of-N sampling

PsyChat 可借鉴的思路

  • 显式行为分类再选策略 — moodcoco 的 Thinker 目前用自然语言分析用户状态，可以考虑引入结构化的行为标签（特别是消极反应的 6 类），让策略选择更精确
  • 检索增强策略选择 — 用 embedding 检索相似历史对话来辅助策略选择，比纯靠 LLM 推理更稳定，与 moodcoco 规划中的 RAG 方向一致
  • 生成-筛选解耦 — M5 的 cross-encoder 筛选机制可以作为 quality gate 引入 Thinker 的 critic 环节
  • 来访者消极反应检测 — 防御、转移话题、焦点脱离等消极行为的识别对 safety 模块有直接价值

架构差异

  • 同步 vs 异步 — PsyChat 五模块串行执行（文本场景），moodcoco 是 cross-turn 异步（语音场景要求即时响应）
  • 专用分类器 vs 通用 LLM — PsyChat 用专用 RoBERTa 做行为分类，moodcoco 依赖通用 LLM 的 prompt engineering
  • 中文专用 vs 多语言 — PsyChat 基于中文 Xinling 数据集，moodcoco 需要覆盖中文+印尼语

局限性

  • 无消融实验 — 论文没有报告各模块单独的贡献度。不清楚是行为识别更重要还是策略选择更重要，也不清楚去掉 M5 筛选器后效果下降多少
  • 单一 baseline — 仅与 ChatGLM2-6B 原始模型对比，没有与 ESConv、MultiESC 等心理对话专用系统对比
  • 数据集受限 — Xinling 数据集为有条件开源的中文咨询数据，规模有限（~22K 条），且行为/策略标注依赖单一来源
  • 串行延迟 — 五模块串行执行，M1 分类 → M2 检索 → M3 组装 → M4 生成 10 条 → M5 逐条打分，延迟不适用于实时语音场景
  • 行为分类静态 — 11 类行为分类来自固定分类法，无法识别训练数据外的新行为模式
  • 无多轮策略演化 — 每轮独立做行为识别和策略选择，没有跨会话的策略演化或来访者变化追踪
  • 评估样本量小 — 人类评估仅 100 个样本、3 名评估者，统计效力有限
