MCTSr-Zero: 原则导向的心理咨询对话生成

AAAI 2026 · Hao Lu, Yanchi Gu, Haoyuan Huang, Yulin Zhou, Ningxin Zhu, Chen Li · arXiv 2505.23229
arXiv: 2505.23229
30 秒版本
问题：MCTS + LLM 在数学/代码等有客观答案的领域有效，但心理咨询对话没有"正确答案"——好的回应取决于共情、伦理、来访者状态等主观因素。
做法：MCTSr-Zero 把 MCTS 的搜索目标从"逼近正确答案"改为"符合 16 条咨询原则的对话轨迹"。引入两种探索模式——Refinement（深度改进单条回应）和 Regeneration + Meta-Prompt Adaptation（切换初始策略，广度探索不同咨询风格）。
结果：用该方法生成 4,000 条合成对话微调的 PsyLLM（90.93 分）超过 Claude 3.7 Sonnet（88.89）和 GPT-4.1（85.65），在 PsyEval 基准上达到 SOTA。
对 moodcoco：这套流水线可直接复用于合成训练数据——用 MCTSr-Zero 批量生成高质量咨询对话，微调小模型做 fast-path 回复。
核心改造：传统 MCTS vs MCTSr-Zero
传统 MCTS (数学/代码)

搜索目标：逼近唯一正确答案

  • Selection：UCT 选最优子节点
  • Expansion：生成下一步推理
  • Simulation：rollout 到终态，验证对错
  • Backpropagation：胜/负信号回传
评判标准 = 答案对不对
终止条件 = 找到正确答案
MCTSr-Zero (心理咨询)

搜索目标：符合领域原则的对话轨迹

  • Selection：UCT 选节点 或 回到根节点触发 Regeneration
  • Expansion：Refinement（改进）或 Regeneration（换策略重生成）
  • Evaluation：LLM 按 16 条原则打分（替代 rollout）
  • Backpropagation：Q 值 + Meta-Prompt 更新
评判标准 = 16 条咨询原则打分
终止条件 = 迭代次数 T
关键转变

传统 MCTS 的节点代表"推理步骤"，树的叶子节点是"最终答案"。MCTSr-Zero 的节点代表"咨询师的完整回应"，搜索不是在找"正确答案"，而是在优化回应质量——让回应越来越贴合共情、伦理、连贯性等原则。没有"正确终态"，只有"更好的轨迹"。

Selection 的两种分支
Refinement（深度）

UCT 选中某个 answer 节点 → 基于该节点的评估反馈（critique + suggestions），LLM 生成改进版回应作为子节点。

类似传统 MCTS 的"沿着有前途的分支继续探索"。

Regeneration（广度）

UCT 选中根节点 P → 触发 Meta-Prompt Adaptation，生成新的候选 meta-prompt，然后用新 prompt 从头生成全新回应。

这是 MCTSr-Zero 的独创——跳出当前策略空间，换一种咨询风格重新开始。

为什么需要 Meta-Prompt Adaptation？

传统 Self-Refine 从单一初始回应出发，反复修改。问题是：如果初始策略就不对（比如用了认知行为疗法，但来访者需要的是情感确认），再怎么 refine 也跳不出这个框。

Meta-Prompt Adaptation 让系统能切换咨询策略——比如从"直接给建议"切换到"先共情再引导"，或从"聚焦问题解决"切换到"探索情绪体验"。每次切换都是有条件的：只有新策略产生了更好的回应才会保留。

原则导向的搜索目标：16 条咨询原则（Constitution）
替代"正确答案"的评判标准

Q 值聚合公式
Q(a) = 1/2 × ( min(Ra) + (1/|Ra|) × Σ Rai )

min(Ra)：所有评估中的最低分（木桶效应——一条原则严重违反就拉低总分）
mean(Ra)：所有评估的平均分（整体质量）
取两者均值，平衡"不能有明显短板"和"整体要好"。

父节点 Q 值更新
Q'(parent) = 1/2 × ( Q(parent) + maxchildren Q(child) )
Q(root) = (1/N) × Σ Q(childi)

父节点：自身得分与最好子节点的均值（好的改进能拉升父节点评价）。
根节点：所有直接子节点的平均（全局视角）。

  • 选取搜索树中 Q 值最高的轨迹

  • 4 x NVIDIA A800 GPU
  • 2 epochs, lr = 1e-4
  • Batch size 1, AdamW 优化器

  • 3 epochs, lr = 5e-7
  • Batch size 1
  • 进一步对齐人类偏好

关键发现
  • PsyLLM（MCTSr-Zero 微调的小模型）超越 Claude 3.7 Sonnet（+2.04 分）和 GPT-4.1（+5.28 分）
  • Large 和 Mini 版本差距极小（0.21 分），说明训练数据质量比模型大小更重要
  • 合成数据微调的小模型 > 未微调的大模型——这是 MCTSr-Zero 的核心价值

Self-Refine → MCTSr：加入树搜索（UCT 选择 + 多分支）比线性 refine 提升约 1 分。MCTS 的结构化探索确实有用。
MCTSr → MCTSr-Zero：加入 Meta-Prompt Adaptation 再提升约 0.7 分。策略层面的广度探索（换咨询风格）有独立贡献。
对 moodcoco 的价值
直接可用：合成数据流水线
  • 核心价值：用 MCTSr-Zero 批量生成高质量咨询对话，微调小模型做 fast-path 回复
  • 论文证明：4,000 条合成数据微调的小模型 > GPT-4.1 级别的大模型
  • 训练成本可控：4 x A800，SFT 2 epochs + SimPO 3 epochs
可借鉴：16 原则评估体系
  • moodcoco 现有 5 维评估（看见情绪/原因/模式/方法 + 安全边界）可以参考这 16 条原则做细粒度拆分
  • 特别是 Resistance Handling（阻抗处理）和 Dialogue Pacing（节奏调谐）两个维度，moodcoco 目前未覆盖
  • PsyEval 的"第三方观察者视角"评估方式值得借鉴——用推断性语言（"系统似乎..."）而非绝对判断
实施路径
  • Phase 1：定义 moodcoco 版"原则宪法"（基于现有 5 维 + 论文 16 维，取并集去重）
  • Phase 2：搭建 MCTSr-Zero 数据生成流水线，用 minimax-m2.7 做搜索引擎
  • Phase 3：生成中文/印尼语咨询对话数据（16 类场景 x 目标市场文化适配）
  • Phase 4：SFT + SimPO 微调 fast-path 小模型
需要注意
  • MCTSr-Zero 的计算成本高（每个 case 要跑 T 次 MCTS 迭代，每次涉及 LLM 多次调用），适合离线数据生成，不适合在线推理
  • 论文的评估用 AI Judge（deepseek-v3），自身可能有偏差——moodcoco 如果用此方法，需要抽样做人工评估校验
  • 16 类场景覆盖面需要根据 moodcoco 目标用户（大学生）做定制
局限性
论文自述
  • 计算成本高：每个 case 需要多次 LLM 调用（Selection + Expansion + Evaluation + Meta-Prompt），只适合离线数据生成
  • AI Judge 偏差：PsyEval 用 deepseek-v3 做评估，AI 评分器自身的偏好和盲点会传递到结果中
  • 缺少人工评估：没有真人心理咨询师对生成对话的质量评定
我们的观察
  • 场景覆盖：16 类心理困扰的分类粒度较粗（如"学业压力"内部差异很大）
  • 文化适配：论文聚焦中文场景，跨文化适用性未验证
  • Meta-Prompt 边际收益：消融实验显示 Meta-Prompt Adaptation 仅贡献约 0.7 分提升，投入产出比需要评估
  • 与真实咨询的差距：合成对话的来访者反应是 LLM 模拟的，可能不反映真实来访者的不可预测性

UCT Selection 公式
UCT(a) = Q(a) + c × √(ln N(P) / N(a))

Q(a) = 节点质量估计
N(P) = 父节点访问次数
N(a) = 当前节点访问次数
c = 探索常数
