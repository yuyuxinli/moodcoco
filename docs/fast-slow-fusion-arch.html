跨轮状态流转机制

📁 文件级桥接（Text / Web 模式）

  • SLOW_GUIDANCE.md — Slow output → 文件 → 下轮 Fast 的 slow_guidance instruction
  • MEMORY.md — Slow write_memory() → 文件 → 下轮 Fast 的 memory_text instruction
  • Fast 有最终决定权，可参考/忽略 slow_guidance

🔄 内存级桥接（Voice 非流式模式）

  • 同轮：slow_deps.fast_deps 共享对象 → 三个 mutation tools 实时写入 fast_deps 字段
  • 跨轮：_persist_slow_state() → self._slow_state.carryover_* → 下一轮 FastThinkDeps 构造
  • carryover 有 LRU 限制：inject[-3:], skills[-2:]

⚡ Voice 流式模式（当前状态）

  • _slow_state 初始化为空 dict，无任何 writer
  • 只读 MEMORY.md + SLOW_GUIDANCE.md（但无 Slow 去写这两个文件）
  • stream_reply 的 dynamic_inject / skill_bundle / retrieval_block 参数始终为空
  • 结论：当前流式路径是纯粹的"嘴"——只管把 LLM 的输出流式说出来，没有任何思考决策注入

Agentic Loop 内部机制

🧠 Fast Agent Loop (pydantic-ai)

  • 模型：create_fast_model()（Doubao lite）
  • System prompt：SOUL + IDENTITY + AGENTS + fast-instructions + fast-tools
  • 动态 instructions（每次 LLM 调用前注入）：
    • inject_memory() — MEMORY.md 内容
    • inject_slow_guidance() — 上轮 SLOW_GUIDANCE.md
    • inject_voice_extras() — Voice 模式下 Slow 同轮注入
  • 7 个 UI tools：ai_message / ai_options / ai_mood_select / ai_praise_popup / ai_body_sensation / ai_complete_conversation / ai_safety_brake
  • Voice 模式下 ai_message → session.say() → raise 退出 loop
  • Text 模式下 loop 正常结束（agent 决定不再调用 tool）

🔮 Slow Agent Loop (pydantic-ai)

  • 模型：create_slow_model()（Minimax m2.7）
  • System prompt：SOUL + IDENTITY + AGENTS + slow-instructions + VOICE_MUTATION_TOOL_GUIDE
  • 动态 instructions：
    • inject_context() — user_message + fast_reply_text + MEMORY.md
  • 读写 tools：list_skills / read_skill / write_memory
  • Voice mutation tools（仅 fast_deps 存在时生效）：
    • slow_inject_to_fast → fast_deps.dynamic_inject
    • slow_attach_skill_to_fast → fast_deps.skill_bundle
    • slow_set_fast_retrieval → fast_deps.retrieval_block
  • output（text 模式）→ 写入 SLOW_GUIDANCE.md
  • UsageLimits: request=4, tool_calls=4
