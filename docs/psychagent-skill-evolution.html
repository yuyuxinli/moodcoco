心理咨询 Agent

Yang et al. · arXiv 2604.00931 · 2026-04
arxiv.org/abs/2604.00931

30 秒版本

现有 AI 心理咨询靠静态数据 SFT，而人类咨询师靠临床实践持续进化。 PsychAgent 提出三引擎闭环：记忆增强规划维持跨 session 连续性， 技能进化引擎从历史咨询轨迹自动提取新技能， 强化内化引擎通过 Rejection Fine-Tuning 将技能写入模型参数。 结果：在 5 个治疗流派上全面超越 GPT-5.4、Gemini-3 和领域专用模型。 消融实验显示技能进化引擎贡献最大。

Skill Evolution Engine 详解

这是论文贡献最大的模块（消融实验 drop 最大）。核心思想：从咨询实践的最优轨迹中自动提取、组织和更新治疗技能。

四级技能层次树

技能库组织为四级层次树 T = (N, E)：

L1 根范式
CBT 人本主义 精神动力 行为疗法 后现代
L2 治疗阶段
个案概念化 核心干预 巩固与预防
L3 元技能
共情建立 认知重构 行为激活 情绪聚焦 ...
L4 原子技能
苏格拉底提问 低门槛流程卡 暂停-回退规则 最小可行行动 ...

技能提取流程

1. 选取最优轨迹 S*
从 N=8 条平行候选 session 中，经多维奖励模型评分后选出最高分轨迹。
2. 定向技能提取 (Targeted Skill Extraction)
模型分析最优轨迹，结合记忆 M 和 session 目标 Goal，抽象出对应元技能下的原子技能：
K_atom ← E_θ(S* | M, Goal)
3. 语义检索最近邻
在现有技能库中检索与新提取技能 K_atom 语义最相似的已有技能 K_ref。
4. 自适应技能管理 (Adaptive Skill Management)
管理策略 π_mgt 做出决策：如果新技能与已有技能差异足够大，追加为新节点；如果是已有技能的变体，合并融合以细化定义。

原子技能的表示格式

每个原子技能包含结构化字段：

  • 触发条件 -- 何时使用这个技能
  • 执行步骤 -- 具体操作序列
  • 最小可行行动 -- 降低用户启动门槛的最简版本
  • 量化阈值 -- 何时判断技能生效
  • 监控规则 -- 持续追踪效果
  • 暂停/回退规则 -- 何时停下、换策略

关键发现：73.29% 是实践增量

73.29% 的提取技能引入了"实践增量" -- 不是发明全新疗法，而是在现有微技能基础上增加：操作排序、最小可行行动、量化阈值、监控循环、暂停/回退规则。这更接近人类咨询师的成长方式：不是学新理论，而是把理论变成可操作的直觉。

-- 具体、可执行、有兜底

Memory-Augmented Planning 机制

为多 session 纵向交互设计的记忆和规划系统。核心思想：咨询不是单轮对话，需要跨 session 的治疗连续性。

记忆状态 M_t = (P_t, H_t)

动态客户画像 P_t

  • 语义级记忆，每次 session 后通过属性提取更新
  • 包含人口学信息、主诉、核心议题、进展状态

情景 Session 摘要 H_t

  • 结构化摘要，渐进式追加
  • 捕捉情绪变化轨迹和干预效果

计划推理

综合累积记忆生成连贯的治疗策略方向：

  • 治疗阶段识别：个案概念化 / 核心干预 / 巩固预防
  • Session 目标制定：具体、可操作的当次目标
  • 只有最优轨迹的结果才更新记忆，确保记忆质量

Reinforced Internalization 方法

目标：将 SEE 提取的显式技能逐步"蒸馏"进模型参数，变成内隐直觉，减少对外部检索的依赖。

Rejection Fine-Tuning (RFT) 流程

1. 平行探索
在每个时间步 t，Agent 生成 N=8 条平行候选 session {S_t^(1), ..., S_t^(N)}，探索不同技能 + 对话组合。
2. 多维奖励评估
使用 LLM-as-a-Judge 对每条候选进行多维评分，涵盖来访者维度（情绪变化、满意度）和咨询师维度（技术运用、联盟质量）。
3. 贪心选择
S_t* = argmax_k R(S_t^(k))
选出最优轨迹。只有这条轨迹的结果会更新记忆，用于下一个 session。
4. 似然最大化训练
用选出的黄金轨迹 T* = {S_1*, S_2*, ..., S_T*} 训练模型，被拒绝的 session 作为隐式负样本。

训练目标

L_RFT(θ) = -∑_t log P_θ(S_t* | H_{t-1}*)

本质：最大化最优轨迹的生成概率。与 RLHF 不同，不需要显式奖励模型参数化，而是直接用拒绝采样构造训练数据。

对 moodcoco 的价值

技能库自动进化

PsychAgent 的 SEE 验证了"从咨询轨迹自动提取技能"的可行性。moodcoco 的 Skill 体系可以借鉴四级层次树和自适应管理策略，从用户实际对话中持续进化技能库，而非依赖人工编写。

73% 是"实践增量"而非新理论

最有价值的不是发明新疗法，而是把已有技能变得更可操作 -- 加上步骤顺序、最小可行行动、暂停规则。这与 moodcoco 的"看见方法"目标高度一致：帮用户找到具体可做的事。

技能表示格式可直接复用

触发条件 + 执行步骤 + 最小可行行动 + 量化阈值 + 监控规则 + 暂停/回退 -- 这套原子技能结构可以作为 moodcoco Skill 定义的参考模板。

RFT 比 RLHF 更轻量

Rejection Fine-Tuning 不需要训练单独的奖励模型，直接用 LLM-as-Judge + 拒绝采样。如果 moodcoco 后续需要用对话数据微调模型，RFT 是比 RLHF 更现实的路径。

核心启示：技能进化 > 记忆 > 参数内化。moodcoco 当前阶段应优先投入技能库的自动进化机制（对应 SEE），而非急于做模型微调（对应 RIE）。先让技能库通过 prompt engineering 和 RAG 运转起来，积累足够高质量轨迹后再考虑内化。

局限性

  • 未经真实临床验证 -- 所有实验在模拟客户上进行，与真实咨询场景的 gap 未知。
  • 不创造新疗法 -- 技能进化本质是对现有技能的操作化改良，不能发现全新的治疗技术。
  • 跨流派迁移有限 -- 功能族（如"共情建立"）可跨流派复用，但具体技能包不能直接迁移。
  • 评估主观性 -- 人工评估 QWK 仅 0.675，反映心理咨询质量评估本身就高度主观。
  • 部分指标天花板效应 -- 感知维度出现 ceiling effect，说明评估基准在某些维度上已经饱和。
  • 安全与隐私 -- 论文承认实际部署需要"加强安全和隐私保护"，但未给出具体方案。
  • 计算成本高 -- 16 块 H200 GPU，N=8 平行探索，729 session 的 rollout，对于大多数团队不现实。
