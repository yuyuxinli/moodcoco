## 图 2 — Fast Loop & Slow Loop 内部（pydantic-ai 视角）

```
                       ┌──────────────────────────────────────┐
                       │     FastThinkDeps (per-turn 实例)    │
                       │  ┌────────────────────────────────┐  │
                       │  │ voice_session: AgentSession    │  │ ◄── voice 模式注入
                       │  │ skill_bundle:  list[str]       │  │ ◄── slow_attach_skill_to_fast
                       │  │ retrieval_block: str           │  │ ◄── slow_set_fast_retrieval
                       │  │ dynamic_inject: list[str]      │  │ ◄── slow_inject_to_fast
                       │  │ (现有文字 chat 字段保留)       │  │
                       │  └────────────────────────────────┘  │
                       └────┬─────────────────────────────────┘
                            │ deps
                            ▼
       ┌────────────────────────────────────────────────────────────┐
       │   fast_agent: Agent[FastThinkDeps, str]                    │
       │   model: minimax-m2.7 (no-thinking, via OpenRouter)        │
       │   max_iter: 3                                              │
       │                                                             │
       │   ┌──────────────────────────────────────────────────────┐ │
       │   │ for iter in 0..2:                                     │ │
       │   │   compile system = base + voice_system_extras()       │ │
       │   │   compile messages = [system, *history, user_msg]    │ │
       │   │   resp = LLM.chat(messages, tools=[7 现有 + 1 新])   │ │
       │   │   if resp has no tool_call → BREAK (LLM 自决 stop)   │ │
       │   │   for tc in resp.tool_calls:                          │ │
       │   │     execute(tc) → record result                      │ │
       │   │ END for                                               │ │
       │   └──────────────────────────────────────────────────────┘ │
       │                                                             │
       │   tools (already have 7 from text chat):                   │
       │     ai_message / ai_options / ai_mood_select /             │
       │     ai_praise_popup / ai_complete_conversation /           │
       │     ai_body_sensation / ai_safety_brake                    │
       │                                                             │
       │   tools (NEW for voice 2.0):                               │
       │     ai_voice_say(text) ─── calls session.say(text)         │
       └────────────────────────────────────────────────────────────┘

                       ┌──────────────────────────────────────┐
                       │     SlowThinkDeps                    │
                       │  ┌────────────────────────────────┐  │
                       │  │ fast_deps: FastThinkDeps  ◄──  │  │  同 turn ref，slow tool 可改
                       │  │ reasoning_trail: list[str]     │  │  跨 turn (writes back to entry)
                       │  │ search_cache: dict             │  │  跨 turn
                       │  │ pending_actions: list          │  │  跨 turn
                       │  │ (现有文字 chat 字段保留)       │  │
                       │  └────────────────────────────────┘  │
                       └────┬─────────────────────────────────┘
                            │ deps
                            ▼
       ┌────────────────────────────────────────────────────────────┐
       │   slow_agent: Agent[SlowThinkDeps, str]                    │
       │   model: minimax-m2.7 (THINKING mode)                      │
       │   max_iter: 3 (per turn)                                   │
       │                                                             │
       │   ┌──────────────────────────────────────────────────────┐ │
       │   │ for iter in 0..2:                                     │ │
       │   │   resp = LLM.chat(messages, tools=[3 现有 + 3 新])    │ │
       │   │   for tc in resp.tool_calls:                          │ │
       │   │     execute(tc) → may mutate fast_deps                │ │
       │   │   if no fast_deps mutation this iter:                 │ │
       │   │     reasoning_trail += "iter {i}: noop" → BREAK       │ │
       │   │ END for                                               │ │
       │   └──────────────────────────────────────────────────────┘ │
       │                                                             │
       │   tools (already have 3 from text chat):                   │
       │     list_skills / read_skill / write_memory                │
       │                                                             │
       │   tools (NEW for voice 2.0):                               │
       │     slow_inject_to_fast(text)                              │
       │       → fast_deps.dynamic_inject.append(text)              │
       │     slow_set_fast_retrieval(block)                         │
       │       → fast_deps.retrieval_block = block                  │
       │     slow_attach_skill_to_fast(name)                        │
       │       → fast_deps.skill_bundle.append(read_skill(name))    │
       └────────────────────────────────────────────────────────────┘
```

## 图 3 — 时序图 (单 turn 立体观)

```
time→  T+0ms   T+200ms       T+800ms       T+1500ms       T+3000ms      T+5000ms
       │      │             │              │             │             │
user   ▆▆▆▆ done speaking
       │
STT    ──────────xfyun────────────►transcript "user_msg"
                                    │
                                    ├─ fast_agent.run() ──────────────────────►done
                                    │  iter 0: ai_voice_say("听到了…") ─────►session.say()─► [user 听]
                                    │  iter 1: ai_voice_say("继续展开…") ──►session.say()─► [user 听]
                                    │  iter 2: stop (LLM 不再 tool_call)
                                    │
                                    └─ slow_agent.run() (并行，async) ───────────────────►runs into next turn
                                       iter 0: list_skills()
                                       iter 1: slow_attach_skill_to_fast("listen")
                                                ↓ 改 fast_deps.skill_bundle
                                                Fast 此时已经在 iter 1 了，但下一 iter 会读到
                                       iter 2: slow_set_fast_retrieval("用户提到妈妈翻日记本")
                                                ↓ 改 fast_deps.retrieval_block
                                       (no further mutation → BREAK)

Pre-LLM ▂▂"嗯让我想想"  ←── doubao-lite 立刻垫话，不阻塞

TTS    ▆▆▆▆"嗯让我想想"  ▆▆▆▆"听到了…"  ▆▆▆▆"继续展开…"
       (pre-LLM)        (Fast iter 0)     (Fast iter 1)
```

**关键时序观察**：
- Pre-LLM 在 200ms 内出声，给用户立刻反馈
- Fast 在 800-3000ms 之间完成 ≤3 句 say
- Slow 跟 Fast 并行跑，但 Slow 的 mutation 影响**下一个 user turn**的 Fast（不影响当前 turn 已说出的话）
- 下一个 turn 时 Fast 起来读 `voice_system_extras()` 就拿到 Slow 准备的 skill / retrieval / dynamic_inject

## 图 4 — 跟 r5 的对比（一图看清差异）

```
┌────────────────────────────── r5 (现状) ─────────────────────────────────┐
│                                                                           │
│   on_user_turn_completed                                                  │
│      ├─ asyncio.gather(                                                   │
│      │    _fast_filler(...)        ── 1 次性 doubao-lite 短回应          │
│      │    _run_merged_decision(...) ── 1 次 doubao 决策 (search+skill)   │
│      │    _run_slow_v1(...)        ── 1 次 minimax 流回应（≤200 token）  │
│      │  )                                                                 │
│      ├─ _run_dp_continue(slow_v1_text)  ── 200ms 硬限决定要不要 v2       │
│      └─ if continue: _run_slow_v2(...)   ── 第二轮 minimax 深回应         │
│                                                                           │
│   全部 hardcoded 在 fast_slow_agent.py（1100 行）                         │
│   不是 agentic loop，都是 hardcoded sequence                             │
└───────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────── 2.0 ──────────────────────────────────────┐
│                                                                           │
│   on_user_turn_completed                                                  │
│      ├─ fast_deps = FastThinkDeps(voice_session=…, skill_bundle=…, …)    │
│      ├─ slow_deps = SlowThinkDeps(fast_deps=fast_deps, …)                │
│      └─ asyncio.gather(                                                   │
│           fast_agent.run(user_msg, deps=fast_deps, msgs=fast_history)    │
│           slow_agent.run(user_msg, deps=slow_deps, msgs=slow_history)    │
│         )                                                                 │
│                                                                           │
│   pydantic-ai 内部各自跑 ≤3 iter 的 tool-call agentic loop                │
│   桥接层（entrypoint.py）只 ~30 行                                       │
│   Slow 跨 turn 状态保留在 self._slow_state（entry instance）             │
└───────────────────────────────────────────────────────────────────────────┘
```

## 控制层次

```
LiveKit Agents (RTC, audio)
   │
   ↓ 提供 STT/TTS/AgentSession/RoomIO
   │
voice_entrypoint.py (~250 行 thin bridge)
   │
   ↓ 委托
   │
Pydantic AI (agentic loop)
   ├─ fast_agent (existing + 1 new tool)
   └─ slow_agent (existing + 3 new tools)

   ↓ 跑模型
   │
LLM provider (minimax-m2.7 / doubao-lite via OpenRouter / Ark)
```

每一层只做自己擅长的，**不重复造轮子**。ng
