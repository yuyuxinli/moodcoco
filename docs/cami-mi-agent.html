CAMI: 用状态推断 + 话题探索
驱动动机访谈的咨询 Agent

CAMI 提出 STAR 框架：先推断用户处于 TTM 哪个改变阶段，再在分层话题树中选择探索方向，最后根据阶段 + 话题选择 MI 策略生成回复。在模拟来访者上达到 53.1% 成功率，显著优于基线。

Yizhe Yang, Palakorn Achananuparp, Heyan Huang, Jing Jiang 等 | GPT-4o / Llama-3.1-70B | 190 sessions, 38 profiles

30 秒版本

问题：现有 LLM 咨询 agent 不知道用户"准备好了没有"，容易在用户还没想改变时就开始给建议。

方案：STAR 框架 = State 推断（用 TTM 判用户在哪个阶段）+ Topic 探索（59 个话题的分层树，动态导航）+ Action 选择（根据阶段选 MI 策略）+ Response 生成与排序（生成 3 个候选，LLM 排序选最佳）。

结果：53.1% 的模拟用户被成功唤起改变谈话（change talk），比最强基线 CoS 高 15 个百分点。状态推断准确率 93%。

对 moodcoco 的意义：TTM 阶段推断可类比到 Hill 探索-领悟-行动阶段，用于动态切换 skill；话题树导航思路可用于情绪原因的结构化探索。

Moderator（会话管理）

独立模块，每轮判断是否结束会话。终止条件：(1) 咨询师或来访者明确结束；(2) 来访者已被唤起改变动机；(3) 达到 50 轮上限。

Client Simulator（来访者模拟）

多模块设计：状态转换模块 + 动态参与度追踪 + 响应生成。比简单 prompt 更真实，能保持跨轮状态一致性。38 个手动标注 profile，每个跑 5 次。

THEORETICAL FOUNDATION

TTM 五阶段 × 咨询策略映射

TTM（Transtheoretical Model of Change）将行为改变分为五个阶段。CAMI 聚焦前三个阶段（Pre-contemplation / Contemplation / Preparation），因为这是 MI 最核心的战场——用户还没行动，需要被唤起改变动机。

1

Pre-contemplation
前意向期

不认为自己有问题，没打算改变

策略：建立信任、确立改变目标、不对抗

2

Contemplation
意向期

意识到问题，但在权衡利弊，矛盾中

策略：倾听、处理矛盾信念、探索两面

3

Preparation
准备期

决定要改变，开始考虑怎么做

策略：提供信息和工具、制定计划

4

Action
行动期

正在执行改变行为

CAMI 未覆盖

5

Maintenance
维持期

持续新行为，防止复发

CAMI 未覆盖

为什么只用前三阶段？

MI（动机访谈）的核心目标是唤起改变谈话（change talk），让用户从"不想改"移动到"准备改"。Action 和 Maintenance 阶段已经超出 MI 的典型工作范围，属于 CBT/行为激活等其他技术的领地。CAMI 精准聚焦 MI 的核心战场。

MODULE 1

State Inference：用户现在在哪个阶段？

状态推断是 STAR 的第一步，也是最关键的一步。它决定了后续所有模块的行为方向。

方法：Zero-shot LLM prompting。将完整会话上下文 + 三个阶段的文字描述喂给 LLM，让它分类。

输入：当前会话的全部历史消息

输出：Pre-contemplation / Contemplation / Preparation 三选一

准确率：

  • GPT-4o：93.32%
  • Llama-3.1-70B：88.56%

推断 → 策略的连接

状态推断的结果以自然语言注入后续 prompt：

"The current client's state is [Contemplation]"

不同阶段触发不同的策略偏好：

  • Pre-C → 偏向 Affirm、Open Question（建立关系）
  • C → 偏向 Complex Reflection（处理矛盾）
  • P → 偏向 Advise with Permission（提供方向）

为什么 Zero-shot 就够用？

TTM 三阶段的区分度高、描述清晰。Pre-C 的用户会说"我没觉得有问题"，C 的用户会说"我也想改但又怕"，P 的用户会说"我打算试试"。LLM 的语义理解能力足以在上下文中捕捉这些信号，不需要 few-shot 样例。93% 的准确率验证了这一点。

MODULE 2

Topic Exploration：在话题树中导航

CAMI 不是随意聊天，而是在一棵预构建的分层话题树中有方向地探索，寻找最能唤起改变谈话的话题切入点。

话题树构建（离线）

  1. 从 AnnoMI 咨询数据集提取 28 个细粒度话题
  2. 用 Wikipedia 分类关系组织为三层层级结构
  3. 用 GPT-4o few-shot 扩展到 59 个细粒度话题

导航操作（在线）

  • Step Into 深入当前话题的子话题
  • Switch 切换到同层的兄弟话题
  • Step Out 退回到父话题重新选择

两阶段探索策略

前 6 轮：广度优先

在 Super Class 层广泛探索，LLM 估算每个话题唤起 change talk 的概率。概率 >40% 的话题成为焦点。

第 7 轮起：深度优先

锁定高概率话题后，用 Step Into / Switch / Step Out 精细导航，寻找最有效的切入角度。

MODULE 3 & 4

Action Selection + Response Generation

A

策略选择（Action Selection）

基于 MISC（Motivational Interviewing Skill Code）框架，LLM 从策略列表中选择 ≤2 个最适合当前 阶段 + 话题 + 上下文 的策略。常用策略包括：Affirm、Open Question、Complex Reflection、Advise with Permission、Simple Reflection 等。

G

候选生成

生成 3 个候选回复：策略 A 单独生成 1 个，策略 B 单独生成 1 个，A+B 融合生成 1 个。每个回复限制 ≤150 字符，避免"咨询师话太多"的问题。

R

排序选优（Response Ranking）

LLM 充当评委，对 3 个候选按 上下文连贯性 和 MI 原则一致性 打分排序，选出最佳回复发送给用户。

为什么要 3 选 1 而不是直接生成？

单策略回复可能过于单一，双策略融合回复可能不够自然。生成多个候选再排序，是 Best-of-N 的思路——利用 LLM 的判别能力（通常强于生成能力）来兜底生成质量。这在对话系统中是成熟做法。

实验设置

MITI 行为计数指标

CAMI 在 MITI（Motivational Interviewing Treatment Integrity）标准下的行为分布更接近真实咨询师：

  • R/Q ratio：反映/提问比，越高越好（咨询师应多反映少提问）
  • %OQ：开放问题占比
  • %CR：复杂反映占比
  • %MIC：MI 一致行为占比

消融实验关键发现

去掉 Topic Exploration 后（CAMI-TE）：

  • 成功率从 53.1% 降至 38.4%（-14.7pp）
  • 无法探索低频但有效的话题（如 Law、Education）
  • 说明话题多样性对唤起 change talk 至关重要
IMPLICATIONS

对 moodcoco 的价值

CAMI 的核心洞察——"先判断用户所处阶段，再选择策略"——与 moodcoco 的"看见"理念高度契合。

1. TTM → Hill 阶段模型的类比

CAMI 用 TTM（Pre-C / C / P）推断改变阶段。moodcoco 可类比到 Hill 的三阶段模型：
探索期（"好烦但说不清"）→ 领悟期（"原来我是害怕被抛弃"）→ 行动期（"下次我试试直接说"）
不同阶段激活不同 skill：探索期用情绪命名，领悟期用模式指出，行动期才给方法。

2. 阶段推断模块可直接复用

CAMI 证明 zero-shot LLM prompting 就能以 93% 准确率推断用户阶段，不需要训练分类器。moodcoco 可以在每轮对话前加一个轻量阶段推断 prompt，根据结果动态选择 skill 组合。这比现在固定的 skill 触发规则更灵活。

3. 话题树 → 情绪原因的结构化探索

CAMI 的三层话题树（5 → 14 → 59）提供了一个结构化探索框架。moodcoco 可以构建"情绪原因树"：
关系 → 亲密关系 → 已读不回 / 冷暴力 / 分手焦虑
自我 → 价值感 → 被否定 / 比较 / 冒充者综合征
这样"看见原因"就不是漫无目的地追问，而是有结构地导航。

4. Best-of-N 回复排序

生成多个候选再排序选优的思路，适合 moodcoco 在关键节点（比如"看见模式"的瞬间）使用。生成 2-3 种不同力度的回复（轻推 vs 直接指出 vs 问句引导），排序选最合适的。牺牲一点延迟换取关键时刻的回复质量。

维度 CAMI (MI/TTM) moodcoco (情绪陪伴/Hill)
阶段模型 TTM: Pre-C → C → P Hill: 探索 → 领悟 → 行动
目标 唤起 change talk 帮用户"看见自己"
话题结构 3 层话题树 (59 topics) 可建情绪原因树（按用户群定制）
策略选择 MISC 策略 (Affirm, Reflect...) Skill 组合 (IFS, EFT, 模式指出...)
核心差异 聚焦"改变动机" 聚焦"情绪觉察"，不推改变
LIMITATIONS

局限性

1. 级联 Prompt 误差累积

STAR 四步都依赖 LLM prompting，每一步的错误会传递给下一步。状态推断错了，策略选择就跟着错；话题选偏了，回复就偏离方向。论文承认这是"sensitivity to the multiple steps of prompting due to the accumulation of generation errors"。

2. 回复仍然太长、问题太多

即使限制了 150 字符，CAMI 的回复仍然倾向于"过度提问"。真实咨询师在很多时候只是安静地反映，而 LLM 总想"推进对话"。这是 LLM 做咨询的通病。

3. 只验证了 MI，未验证其他流派

STAR 框架是否能迁移到 CBT、IFS、EFT 等其他治疗流派？论文没有探索。对 moodcoco 来说，Hill 模型和 IFS/EFT 的阶段定义与 TTM 不同，需要重新设计状态推断的 prompt。

4. 模拟来访者 =/= 真人

所有实验基于 GPT-4o 模拟的来访者，真人的反应模式、矛盾程度、情绪波动远比模拟复杂。53.1% 的成功率在真人场景中大概率会下降。

5. 话题树是静态的

59 个话题从 AnnoMI 数据集提取 + GPT-4o 扩展，没有根据用户反馈动态更新的机制。对于特定人群（如 moodcoco 的 18-24 岁女性），需要定制化的话题体系。
