AFlow: Affective Flow Language Model

Zou, Wang, Shen, Xiao, Ma, Li, Mao & Cambria · 2026-02 · Chongqing Univ / NUS / NTU
arXiv 2602.08826  ·  GitHub
30 秒版本
问题：现有 ESC (Emotional Support Conversation) 对齐方法只用结局奖励或单轮偏好来训练——中间轮的策略选择得不到有效信号，导致策略不连贯、前期支持行为与后续目标脱节。
方案：AFlow 把多轮对话建模为有向无环图上的 affective flow（情感流），用 GFlowNet 的流守恒约束将结局偏好反向传播到每个中间状态，让策略序列自动保持全局一致性。
效果：Qwen-2.5-7B 上实现的 AFlow 在策略 F1 和响应多样性上全面超越 GPT-4o、Claude-3.5，同时保持低困惑度。
对 moodcoco：slow agent 的多轮规划可以直接借鉴 subpath flow-balance 思想——用流守恒把 session 结束时的情绪改善信号回传到每轮策略决策。

AFlow 解决的三个核心痛点

(i) 上下文敏感性

现有方法无法充分建模轮级上下文演变——支持的时机和强度随对话进展变化，但训练信号没有反映这一点。

(ii) 信用分配

偏好方法依赖稀疏的单轮/结局级监督，无法将最终效果归因到更早的策略决策（credit assignment 断裂）。

(iii) 情感动力学

训练信号不反映细粒度的情感变化，阻碍了长期策略连贯性与心理学实践的对齐。

Affective Flow 建模机制

AFlow 把对话轨迹 τ = (s0, a0, s1, a1, ..., sT) 视为有向无环图上的流网络，其中每个节点是对话前缀状态 st，每条边是策略动作 at。核心约束：流守恒——对任何非终端节点，流入量 = 流出量。

Subpath-Level Flow-Balance Objective 详解

1. 对话建模为 MDP

状态 st ∈ S 编码到第 t 轮的对话历史，动作 at ∈ A 是策略选择。终端状态 sT 被赋予非负终端奖励 R(sT) ≥ 0。

2. Affective Flow 参数化

状态流定义为 MCTS 搜索值与可学习评估模型的乘积：

状态流 F(s) = Q̂(s) · Vφ(s)
Q̂(s) 来自 MCTS backpropagation；Vφ(s) 是可训练的参数化值函数。

3. 边流与流守恒

边流 F(s → s') 定义为状态流乘以策略概率。对非终端节点强制流守恒：

流守恒 (非终端) ∑s'∈Pred(s) F(s' → s) = ∑s''∈Succ(s) F(s → s'')
这保证偏好信号可以从终端状态沿搜索树反向传播到任意中间节点。
边流分解 (前向) F(si → si+1) = F(si) · πθ(ai | si)
边流分解 (后向) F(si → si+1) = F(si+1) · πB(si | si+1)
πB 是后向策略。在搜索树中每个节点有唯一父节点，所以 πB(si | si+1) = 1。

4. Subpath 流平衡约束（核心贡献）

对轨迹 τ 上任意子路径 (sm, ..., sn)，流守恒递推可得：

Subpath 流平衡 F(sn) = F(sm) · ∏i=mn-1 πθ(ai | si)

取对数 → log(Q̂(sn)Vφ(sn)) - log(Q̂(sm)Vφ(sm)) = ∑i=mn-1 log πθ(ai | si)
记 ΔFm,n = log(Q̂(sn)Vφ(sn)) - log(Q̂(sm)Vφ(sm))，Δπm,n = ∑ log πθ(ai | si)

5. 训练目标

策略损失 (所有子路径) Lpolicy = ∑τ∈T ∑0≤m<n≤Tτ (ΔFm,n - Δπm,n)2
对每条轨迹 τ，遍历所有 O(T2) 个子路径对，强制流差与策略对数概率差一致。这是 credit assignment 的核心机制。
边级偏好排序损失 Levaluate = E(st, aw, al) max(0, γ - (Vφ(st, aw) - Vφ(st, al)))
在同一状态 st 下，Q̂(st, aw) > Q̂(st, al) 的策略对构成偏好信号。γ 是 margin 超参。
总目标 LAFPO = Lpolicy + λ · Levaluate
λ 控制 subpath 流平衡与边级偏好的权衡。

中间轮 vs 仅结局奖励：关键差异

传统方法（RLHF / DPO / 结局奖励）

  • 只在对话结束时给一个标量奖励
  • 中间轮策略选择无直接梯度
  • 早期探索阶段的好决策得不到 credit
  • 策略可能在 Exploration 和 Action 阶段不连贯
  • Value gap ΔQ 分布散乱，区分度低

AFlow（Subpath Flow Balance）

  • 每个子路径都有流平衡约束 → 密集信号
  • O(T2) 个子路径对提供 credit assignment
  • 流守恒自动把终端偏好反传到初始状态
  • Exploration → Comforting → Action 全程连贯
  • Value gap ≈1.8 正向偏移，分离度 ΔQ*≈0.63
Figure 3 解读：Value Gap 分布

(a) Value Gap ΔQ 分布

SFT 和 DPO 的 ΔQ 分布中心在 0 附近 — 无法区分好坏策略分支。AFlow 的分布正偏约 1.8，说明学到的值函数能有效区分高/低终端奖励的分支。

(b) 逐轮分离度 ΔQ*

DPO 的分离度在后期轮次快速衰减至 0。AFlow 保持约 0.63 的稳定分离 — 即使到第 7-8 轮，值函数仍能区分好坏策略。

策略多样性分析 (RQ5)

AFlow 的策略分布与人类 ground truth 高度一致，覆盖全部 8 种治疗策略：

Clarification Restatement Emotional Validation Exploration of Situation Affirmation Self-disclosure Coping Plan Solution Offering

人类对话呈高熵分散分布（所有策略均有覆盖），而模式坍缩的方法会集中在少数"安全"策略上。AFlow 保持了专家级的多样性，同时遵循 Exploration → Comforting → Action 的自然阶段进展。

对 moodcoco slow agent 的价值

直接可借鉴的三个设计原则

  • 流守恒做 credit assignment：moodcoco slow agent 的多轮规划天然适合 flow-balance 框架。Session 结束时的情绪改善指标（对应 R(sT)）可以通过流守恒约束反传到每一轮的策略决策，不需要额外训练 reward model。
  • MCTS 搜索做离线策略评估：用 MCTS 在历史对话上搜索策略树，获取 Q(s,a) 值函数，为 slow agent 的 "思考" 提供定量的策略选择依据，而不是纯靠 prompt 引导。
  • Affective Reasoning 做在线推理：score(a|s) = logπ(a|s) + Vφ(s,a) 这个公式可以直接用于 slow agent 的策略选择——策略先验概率 + 学到的情感价值估计的组合，计算开销极低。
落地路径
Phase 1
在 moodcoco 历史对话上跑 MCTS 搜索，构建 Q(s,a) 表。Rewarder 用 slow agent 本身做四维度打分（Empathy / Info / Humanoid / Strategy）。
Phase 2
用 AFPO 目标微调 slow agent 的策略选择模块（或 LoRA），使其在推理时自动选择流平衡一致的策略序列。
Phase 3
在线推理时，slow agent 用 Affective Reasoning 公式替代纯 prompt 策略选择，通过 Vφ 值函数提供定量策略评分。
需要注意的适配问题

1. 策略集合：AFlow 用 ESConv 的 8 种策略。moodcoco 的策略集需要根据实际场景重新定义（可能更细粒度，或增加中文语境的特有策略）。

2. MCTS 成本：每条对话需要多次 LLM 调用做搜索。可以先在少量高质量对话上做，然后用蒸馏方式扩展。

3. 评估维度权重：AFlow 的 wS=0.2 强调策略效能。moodcoco 可能需要更高的 Empathy 权重（情绪陪伴场景 vs 问题解决场景）。

局限性

  • !
    MCTS 搜索成本高
    每条种子对话需要多轮 LLM 调用做 Selection/Expansion/Rollout，训练数据构建的计算成本是标准 DPO 的数倍。论文用 1000+500 条种子对话，规模有限。
  • !
    Seeker 模拟器的保真度
    MCTS 中的用户侧由 LLM 模拟，其行为分布与真实求助者可能存在偏差。模拟器的质量直接影响 Q(s,a) 估计的准确性。
  • !
    策略集合固定
    论文将策略合并为 8 类（来自 ESConv/ExTES 标注），不支持动态策略发现。在新场景或不同文化语境下可能需要重新定义策略空间。
  • !
    长对话的 O(T2) 子路径
    Lpolicy 遍历所有子路径对，复杂度为 O(T2)。论文称 "bounded horizon 下可控"，但对超长 session（>15 轮）的扩展性未经验证。
  • !
    后向策略的简化假设
    πB(si|si+1) = 1 依赖搜索树中每个节点唯一父节点的特性。在实际对话图（非树）中，这个假设不成立，需要显式参数化后向策略。
  • !
    评估限于英文 ESC 数据集
    仅在 ESConv 和 ExTES 上评估，均为英文。跨语言泛化（特别是中文心理支持对话）未验证。
